# ROADMAP — Қақпан (Qaqpan)

> План по фазам. Каждая фаза заканчивается gate. Код — только после Gate 0.
> Версия: 1.0 (2026-11-13).

## Принципы

- Контракты → моки → параллельная работа бэка и фронта → интеграция → бенчмарк → полировка.
- Один шаг = один проверяемый результат.
- Фронтендер никогда не ждёт бэкенд: с первого дня работает по мокам.
- Если не влезаем — резать фичи робота-мошенника, но не трогать FSM, 3 экрана и демо-сценарий.

## Что резать при отставании

В порядке приоритета (режем первое — менее важное):

1. Графики «До vs После» → просто таблица метрик.
2. KZ-язык → только RU (добавить KZ позже, если время будет).
3. Число сценариев робота: 500 → 200 → 100.
4. Explainable AI (объяснения для дочери) → статический шаблон вместо генерации.
5. Анимации и полировка UI → работающий минималистичный интерфейс.

**Не резать:** FSM и все 5 веток, 3 экрана, real-time синхронизацию, демо-кнопки, Baseline-сравнение.

- Если gate красный — фиксируем, не идём дальше.
